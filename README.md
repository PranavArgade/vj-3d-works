# VJ 3D Works — Bill & Invoice Generator

Interactive web application for generating professional 3D printing bills, quotations, and tracking orders.

## Features
- **Invoice & Quotation Generator**: Dynamic calculations based on 3D printing material weight (PLA, PETG, ABS, TPU, ASA), print hours, hourly rates, and quantity.
- **Labor & Discounts**: Configurable labor costs and dual percentage/flat discounts.
- **Google Sheets Order Tracker Sync**: 1:1 mapping for syncing orders directly to Google Sheets.
- **Export & Print**: Native print-to-PDF formatting tailored for invoices.
- **Order Analytics**: Built-in summary dashboard tracking revenue, volume, and material usage.

## Getting Started
Open `Bill Generator.html` in your browser or run via Live Server inside Antigravity IDE / VS Code.
